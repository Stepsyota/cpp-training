# Контекст агента «учебник C++» (`books/`)

Этот файл — **источник правды для чатов, которые пишут тома**, а не упражнения.
Новый агент: прочитай **сначала здесь**, потом `books/README.md`, потом `META.md`
конкретного тома.

Язык с хозяином репозитория: **русский**. Термины C++/STL в тексте книги — **английские**
с кратким пояснением при первом появлении в главе.

---

## Роль и границы

| Делает агент книги | Не делает |
|--------------------|-----------|
| План и текст томов в `books/vol-XX-.../` | Решения `task.cpp`, правки CI/CMake без запроса |
| `SUMMARY.md`, `book.toml`, `META.md`, главы `.md` | Коммит/пуш без явной просьбы |
| Стиль под Kindle + mdBook → EPUB | Подмена `multithread/solutions/` и спойлеры задач |

**Репетитор** (практика, «подтолкни») и **автор книги** — лучше **разные чаты**
(см. том 0, `ch03-tutor-chat.md`).

## Стиль манускрипта (важно)

После обратной связи «мало текста на странице Kindle» зафиксировано:

- Это **учебник**, не конспект: **связные абзацы**, сценарии, мотивация, разбор после кода.
- Меньше цепочек `###` с одной строкой; списки — в резюме и вопросах, не вместо объяснения.
- Абзацы **короткие** (узкий экран), но главы **объёмные** по смыслу (~180–250+ строк md
  на главу для среднего тома; том 1 ~2700 строк md на 14 глав).
- Код: обычно **до ~10 строк**; длинное — дробить или «суть в строках X–Y».
- Широкие таблицы избегать.
- В конце **каждой** главы: **«Вопросы для самопроверки»** (3–5), **«Обсуждение с репетитором»**
  (`Том: N · Глава: ch0K · Файл: ch0K-....md`), ссылка **«Дальше по курсу»**.

Эталон тона: `vol-01-keywords/src/ch01-lexicon-how-to-read.md`, `ch04-qualifiers.md`.

**Не спойлерить** готовый код упражнений `multithread/` / `cicd/`; можно теорию паттернов
(пул, bounded queue) без эталонной реализации.

## Структура одного тома

```
books/vol-XX-name/
  book.toml          # title без ':' и '+' (имя .epub строится из title)
  README.md          # сборка, дата черновика
  META.md            # цель, стандарт, статус, открытые вопросы, план оглавления
  src/
    SUMMARY.md       # оглавление mdBook
    introduction.md
    ch01-....md      # kebab-case, латиница
```

Сводный статус серии: `books/README.md`.

## Сборка EPUB (mdBook 0.5)

На машине хозяина: **mdbook** (dnf или cargo), **mdbook-epub** (обычно `cargo install mdbook-epub`).

```bash
export PATH="$HOME/.cargo/bin:$PATH"
cd books/vol-XX-name
mdbook build    # НЕ mdbook epub — такой подкоманды нет в 0.5
```

- HTML: `book/html/`
- EPUB: `book/epub/<title>.epub`

**Ограничение `book.toml` → `title`:** символы **`:`** и **`+`** ломают имя файла EPUB
(например `Cpp` вместо `C++`). На Kindle в библиотеке видно полный `title` тома.
