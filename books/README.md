# Учебник C++ (mdBook → EPUB)

**Контекст для агента-книги:** [`BOOK-CONTEXT.md`](BOOK-CONTEXT.md) — читать в новом чате перед правками томов.

Теоретические тома для чтения на Kindle и возврата к темам без привязки к одному чату.
Практика — в `multithread/`, `cicd/` и будущих треках репозитория `training`.

| Том | Папка | Название | Статус (md в `src/`) |
|-----|--------|----------|----------------------|
| 0 | `vol-00-guide` | Как пользоваться курсом | книжный навигатор (~438) |
| 1 | `vol-01-keywords` | Ключевые слова и эволюция языка | **эталон** (~2734) |
| 2 | `vol-02-lambdas` | Лямбды и объекты-функции | раздувание готово (~2166) |
| 3 | `vol-03-concurrency` | Многопоточность и модель памяти | ~2583 |
| 4 | `vol-04-async` | Асинхронность, futures, coroutines | ~2717 |
| 5 | `vol-05-toolchain-flags` | Компиляция, флаги, линковка | ~2594 |
| 6 | `vol-06-debugging` | GDB и отладка в IDE | ~2567 |
| 7 | `vol-07-sanitizers` | ASan, UBSan, TSan | ~2606 |
| 8 | `vol-08-oop` | ООП и SOLID | ~2580 |

Подробнее: [`EXPANSION-STATUS.md`](EXPANSION-STATUS.md).

Глубина серии: **R+P+I** (справочник, связь с практикой, плотные §).
Эталон toolchain: **GCC/Clang на Linux (Fedora)**; MSVC — глава отличий в томе 5.
База упражнений репозитория: **C++17**; в книге фичи **C++20/23** помечены явно.

Сборка одного тома — см. `vol-XX-.../README.md`.

**Все EPUB в одной папке:** [`epub/`](epub/) — после сборки запусти из корня репо `./books/sync-epub.sh` (или `--copy-only`, если тома уже собраны).
