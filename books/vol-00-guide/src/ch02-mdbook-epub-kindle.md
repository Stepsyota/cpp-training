# Глава 2. Книга и Kindle

## Зачем эта глава

Тома собираются **mdBook** из Markdown в `src/`. Один том — один EPUB для Kindle Paperwhite. Здесь — как собрать локально, что ожидать от вёрстки на e-ink и как читать **код** на маленьком экране.

## Структура одного тома

```
books/vol-00-guide/
  book.toml          # название, язык, выходы html/epub
  README.md          # команды сборки, дата черновика
  META.md            # цель тома, стандарт, открытые вопросы
  src/
    SUMMARY.md       # оглавление (обязательно актуально)
    introduction.md
    ch01-....md
```

Имена файлов глав: **латиница, kebab-case** (`ch03-tutor-chat.md`).

Правила для авторов (и для тебя, если правишь текст):

- короткие абзацы;
- код **короткий** (обычно до ~10 строк); длинное — дробить или «суть в строках 3–7»;
- широкие таблицы избегаем; в этом томе таблицы узкие;
- в конце каждой главы — вопросы и строка «Обсуждение с репетитором».

## Установка инструментов (Fedora / Linux)

**mdBook** — генератор сайта и входная точка:

```bash
cargo install mdbook
# или: sudo dnf install mdbook   # если есть в репозитории
```

**mdbook-epub** — отдельный рендерер (плагин), не подкоманда mdBook:

```bash
cargo install mdbook-epub
export PATH="$HOME/.cargo/bin:$PATH"
```

Проверка:

```bash
mdbook --version
which mdbook-epub
```

В **mdBook 0.5** команды `mdbook epub` **нет** — это нормально. EPUB появляется после `mdbook build`, если в `book.toml` есть `[output.epub]` и в `PATH` есть `mdbook-epub`.

## Сборка

Из корня тома:

```bash
cd books/vol-00-guide
mdbook build
ls book/epub/*.epub
```

- HTML обычно в `book/html/`.
- EPUB — в `book/epub/`; имя файла строится из поля `title` в `book.toml` (без символов `:` и `+`).

Перед отправкой на Kindle имеет смысл один раз открыть EPUB в **Calibre** или **foliate**: оглавление, код, переносы.

## Метаданные без обложки

В `book.toml` заданы `title`, `authors`, `language = "ru"`. **Обложку не делаем:** на Kindle в библиотеке видно название книги — у каждого тома своё поле `title` с номером тома и темой, этого достаточно, чтобы отличать EPUB.

Версия черновика тома фиксируется в `README.md` и `META.md` (дата), не обязательно дублировать в `title`.

## Kindle Paperwhite: практика чтения

**Оглавление.** В mdBook EPUB оглавление строится из `SUMMARY.md`. На Kindle: Menu → Go to → Chapter — проверь, что три главы тома 0 видны.

**Код.** Моноширинный блок на 6″ переносится. В глубоких томах автор дробит листинги; если строка всё равно длинная — читай на ПК (`mdbook serve` для HTML) или увеличь шрифт и листай горизонтально (не идеально, но для коротких фрагментов сойдёт).

**Ссылки.** Внутренние ссылки между главами одного тома работают в ридере; ссылки на файлы репозитория (`multithread/...`) в Kindle **не кликабельны** как git — держи клон репо на машине, где кодишь.

**Закладки и заметки.** Kindle синхронизирует закладки между устройствами; для «вернуться к memory order» удобно закладить начало соответствующей главы тома 3, а не всю книгу.

**Тёмная тема.** mdBook HTML умеет темы; EPUB на Paperwhite — светлый фон по умолчанию. Это нормально для e-ink.

## `mdbook serve` (опционально)

Для правки текста на большом экране:

```bash
cd books/vol-00-guide
mdbook serve --open
```

Сервер пересобирает при сохранении `.md`. EPUB при этом не обновляется автоматически — после порции правок снова `mdbook build`.

## Типичные проблемы

| Симптом | Что проверить |
|---------|----------------|
| Пустое оглавление | Есть ли пункты в `src/SUMMARY.md`, пути без опечаток |
| Глава не в книге | Файл не добавлен в `SUMMARY.md` |
| Нет `.epub` после build | В `PATH` ли `mdbook-epub`; есть ли `[output.epub]`; допустим ли `title` (без `:` и `+`) |
| Кракозябры | `language = "ru"` и UTF-8 в файлах |

## Отправка на Kindle (Send to Kindle)

Типичный путь на Linux:

1. Собрать EPUB: `mdbook build` в папке тома — или все тома разом: из корня репо `./books/sync-epub.sh` (копии в `books/epub/`).
2. Открыть файл в **Calibre** → «Отправить на устройство» или конвертировать в AZW3, если ридер капризничает с EPUB.
3. Либо загрузить EPUB через веб **Send to Kindle** (привязан к аккаунту Amazon) — файл появится в библиотеке Paperwhite после синхронизации Wi‑Fi.

Имя файла берётся из `title` в `book.toml`. Если на устройстве два тома слишком похожи — проверь, что в `title` есть номер тома и тема (`Cpp Training — Том 3 — …`).

После обновления глав в git **старый EPUB на Kindle не обновится сам** — пересобери и отправь снова. Закладки на старой версии могут съехать, если сильно менялось оглавление.

## Версии и «черновик»

Дата и статус тома — в `README.md` и `META.md` рядом с `book.toml`. Это не попадает в EPUB автоматически; для себя можно вести заметку «читал сборку от 2026-10-10». Серия целиком: `books/README.md` и `books/EXPANSION-STATUS.md` (объём глав, готовность).

Если глава в репозитории **длиннее**, чем в твоём старом EPUB — ты как раз в ситуации «книжное издание»: тома 2–8 доведены до плотности тома 1 (~2600 строк на том, кроме тома 0 и эталона тома 1).

## Краткое резюме

- Один том = `book.toml` + `src/SUMMARY.md` + главы `.md`.
- Сборка: `mdbook build` (для EPUB нужен `mdbook-epub` в `PATH`).
- Kindle: оглавление из `SUMMARY.md`, короткие листинги; репозиторий с кодом — на ПК.
