# 08. Архив

Есть пачка свитков (`archive.hpp`) и печать `seal`. Проставить печати
по одному — долго. Нужен `parallel_map`: разрезать диапазон на куски,
отдать куски потокам, собрать вектор результатов **в том же порядке**.

Пишешь только `parallel_map.hpp`. Это шаблон — весь код в заголовке.

## Что должно получиться

- `result[i] == fn(input[i])` для всех i;
- пустой вход даёт пустой выход;
- работа идёт в нескольких потоках, не в вызывающем (если потоков ≥ 2
  и элементов хватает);
- лишних потоков нет: `n_threads > size` не должен рожать пустые `join`.

## Подсказка

```
out.resize(n);
для t в 0 .. n_threads-1:
    begin = t * n / n_threads
    end   = (t + 1) * n / n_threads
    поток: for i in [begin, end): out[i] = fn(input[i])
join все
```

Потоки пишут в разные `out[i]` — гонки нет. Захватывать `out` и `input`
можно по ссылке: `join` до возврата из функции, векторы ещё живы.

Не используй `input[0]` в `decltype`, если вектор может быть пуст —
отсюда в сигнатуре `std::invoke_result_t`.
