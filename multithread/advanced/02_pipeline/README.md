# 07. Конвейер завода

Три цеха уже написаны в `factory.cpp`:

```
штамп  →  [очередь]  →  покраска  →  [очередь]  →  упаковка
```

Без очереди штамповщик не знает, куда класть деталь, маляр — откуда брать.
Это классический producer–consumer. Ты пишешь только `bounded_queue.hpp`.

## Что должно получиться

- `push` ждёт, если очередь заполнена до `capacity`;
- `pop` ждёт, если пусто, и возвращает `false`, когда очередь закрыта и пуста;
- `close` будит всех спящих — иначе маляр навсегда застрянет после последней детали;
- ёмкость 1 тоже должна пропустить всю партию (узкое горло, не поломка).

Lost wakeup здесь тот же, что в лифте: `wait` только с предикатом.

## Подсказка

Два условия — две `condition_variable` (или одна на оба предиката).
Флаг `closed` меняй под тем же мьютексом, что и очередь.

`push`: ждать `size < cap || closed`. Если закрыта — выйти, не класть.
`pop`: ждать `!empty || closed`. Пусто и закрыто → `false`.
После `push` буди ждущих `pop`, после `pop` — ждущих `push`.
`close`: флаг + `notify_all` на обе cv.
