# Крупные задачи

Готовые цеха уже стоят. Тебе нужно написать **модуль-связку**, без которого
остальные части не стыкуются.

Иди по порядку: пул → очередь конвейера → параллельный map.
Каждая опирается на пятёрку из `beginner/` и на предыдущую крупную.

| # | Папка | Ты пишешь | Уже есть |
|---|--------|-----------|----------|
| 6 | `01_thread_pool` | `ThreadPool` | заказы и кузница, которая сдаёт их в пул |
| 7 | `02_pipeline` | `BoundedQueue` | штамп, покраска, упаковка |
| 8 | `03_parallel_map` | `parallel_map` | архив документов и функция штампа |

```bash
cd multithread
cmake -S . -B build
cmake --build build --target 06_thread_pool
./build/06_thread_pool
```

Или `./check.sh` — прогонит и пятёрку, и эти три.

Править только файлы из графы «ты пишешь». Остальное — спецификация.
