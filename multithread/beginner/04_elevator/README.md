# 04. Лифт

Пассажиры ждут кабину. Кто-то нажимает кнопку вызова — лифт «приезжает»,
и всех ждущих нужно разбудить.

Есть тонкость: вызов может произойти **до** того, как пассажир начал ждать.
Голый `cv.wait(lock)` в этом случае заснёт навсегда — сигнал уже ушёл,
и больше его никто не повторит. Это классическая lost wakeup.

Допиши `wait_for_elevator` и `call_elevator` в `task.cpp`.

## Что должно получиться

1. Поток в `wait_for_elevator` спит, пока не вызовут лифт.
2. После `call_elevator` он просыпается.
3. Если `call_elevator` уже отработал, последующий `wait_for_elevator`
   возвращается сразу.

## Подсказка

- Ждать: `std::unique_lock<std::mutex>` и `cv.wait(lock, предикат)`.
  Предикат — `arrived == true`.
- Будить: под `std::lock_guard` выставить `arrived = true`, затем
  `notify_all()` (или `notify_one()` — здесь пассажир один, оба варианта ок).
- Флаг меняй только под тем же мьютексом, на котором ждёшь.

## Проверка

```bash
cmake --build build --target 04_elevator
./build/04_elevator
```
