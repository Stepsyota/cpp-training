# 03. Оракул

Вопрос нельзя задать самому — его относит гонец и приносит ответ.
`question` должен выполниться в **другом** потоке, а ты возвращаешь строку,
которую он посчитал.

Допиши `ask_oracle` в `task.cpp`.

## Что должно получиться

- возвращается ровно то, что вернул `question`;
- `question` бежит не в вызывающем потоке;
- `ask_oracle` не возвращается, пока гонец не закончил.

## Подсказка

Короткий путь: `std::async(std::launch::async, ...)` и `.get()`.
Подойдёт и связка `std::promise` / `std::future` + свой `std::thread`.

Нужны заголовки `<future>` и, если пойдёшь через поток, `<thread>`.

`std::launch::async` важен: без него `async` имеет право выполнить задачу
лениво в том же потоке.

## Проверка

cmake --build build --target 03_oracle
