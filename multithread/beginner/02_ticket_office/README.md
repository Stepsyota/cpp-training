# 02. Театральная касса

Восемь окошек продают билеты одновременно и пишут в один счётчик
`tickets_sold`. Обычный `++` здесь небезопасен: два потока могут прочитать
одно и то же число и оба записать `n + 1` — одна продажа исчезает.

Допиши `sell_ticket` в `task.cpp`.

## Что должно получиться

После 8 × 100000 продаж счётчик равен ровно 800000.

## Подсказка

`std::lock_guard<std::mutex>` вокруг увеличения. Мьютекс уже передают
в функцию — его не нужно создавать заново.

## Проверка

```bash
cmake --build build --target 02_ticket_office
./build/02_ticket_office
```
