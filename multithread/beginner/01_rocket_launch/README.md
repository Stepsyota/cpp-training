# 01. Стартовый стол

Ты — руководитель пуска. Предполётную проверку делает офицер безопасности,
и она **обязана** идти в отдельном потоке: пульт руководителя в это время
занят другими делами. Но кнопку «пуск» жать нельзя, пока проверка не
закончится.

Допиши `run_prelaunch_check` в `task.cpp`.

## Что должно получиться

- `check` выполняется **не** в том потоке, который вызвал функцию;
- к моменту возврата из `run_prelaunch_check` `check` уже завершён.

Синхронный вызов `check()` тесты отвергнут: идентификаторы потоков совпадут.

## Подсказка

`std::thread` и метод `join()`. Не забудь `#include <thread>`.

## Проверка

```bash
cmake --build build --target 01_rocket_launch
./build/01_rocket_launch
```
