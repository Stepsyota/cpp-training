# Многопоточность в C++

Если с потоками ещё не работал — сначала прочитай [THEORY.md](THEORY.md).
Там ровно тот минимум, после которого можно открывать первую задачу.

Пять коротких задач: в каждой нужно дописать **несколько строк** в `task.cpp`.
Потом три крупных: пишешь модуль, который склеивает уже готовые части.
Тесты скажут, получилось или нет.

## Как работать

```bash
cd multithread
cmake -S . -B build
cmake --build build
./build/01_rocket_launch   # и так далее
```

Или всё сразу:

```bash
./check.sh
```

В пятёрке править только `beginner/0X_*/task.cpp`. В крупных — только свой
модуль (см. таблицу). Остальное не трогай: это спецификация.

## Задачи

| # | Папка | Тема | Что написать |
|---|--------|------|----------------|
| 1 | `01_rocket_launch` | `std::thread` + `join` | запустить работу в другом потоке и дождаться её |
| 2 | `02_ticket_office` | `std::mutex` | защитить общий счётчик |
| 3 | `03_oracle` | `std::async` / `future` | получить результат из другого потока |
| 4 | `04_elevator` | `condition_variable` | ждать сигнала и не потерять его |
| 5 | `05_highscore` | `std::atomic` + CAS | обновить максимум без гонки |

Иди по порядку: каждая задача опирается на идею предыдущей.
